# Message catalog

Every string the kit generates, with its id, English text and the values it receives. Translate these ids in your dictionary, or override single ones with `translations`; see [Internationalization](i18n.md).

Plural families list one id per CLDR category (`.one`, `.other`, and for RSVP counts every category). A translation only needs the categories its language uses.

This page is generated from the package's built-in English catalogue.
